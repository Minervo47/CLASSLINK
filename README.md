

# ClassLink

ClassLink is a Python-based application designed to help students and class representatives manage assignments efficiently.

## Description

ClassLink allows the Head of Class to post assignments while other students can view them. The project is being built as part of my Python learning journey and will continue to grow with new features over time.

## Current Features

- User enters their name.
- User selects their role (Head of Class or Student).
- Head of Class can add assignments.
- Students can view available assignments.

## Planned Features

- Add multiple assignments.
- Save assignments to a file.
- Edit and delete assignments.
- Assignment deadlines.
- Notifications and reminders.
- User authentication.
- Graphical User Interface (GUI).
- Mobile and web versions.
